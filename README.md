# Playwright Python Automation Project

## Overview
This repository contains Playwright automation scripts written in Python.  
It demonstrates web automation testing, including login, form filling, and validations.  
All project files, tests, and scripts are included as-is for reference and certification purposes.

---

## Project Structure
playwright-project/
├── api/ # Optional API scripts
├── pages/ # Page object models
├── reports/ # Test execution reports
├── test-results/ # Screenshots or test results
├── test_data/ # Any test input data
├── tests/ # Playwright automation test scripts
│ ├── test_example.py
│ └── test_sample.py
├── main.py # Optional helper scripts
├── requirements.txt # Python dependencies
├── pytest.ini # Pytest configuration
└── README.md # Project documentation
